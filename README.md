# Pancreatic Cancer Detection using CT Scan (U-Net)

This project focuses on segmenting pancreatic regions from CT scan images using a U-Net deep learning model to support early detection of pancreatic cancer.

---

## Overview
Pancreatic cancer is often detected at late stages due to subtle early symptoms. This project aims to leverage medical imaging and deep learning to assist in identifying pancreatic regions from CT scans, forming a foundation for early diagnosis systems.

---

## Work Completed
- Implemented U-Net architecture for medical image segmentation  
- Performed preprocessing on CT scan data (normalization, resizing)  
- Initiated model training for pancreas region detection  

---

## Current Status
- Model is under development and optimization  
- Working on improving segmentation accuracy
