Pancreatic Cancer Detection using CT Scan (U-Net)

This project focuses on segmenting pancreatic regions from CT scan images using a U-Net deep learning model to assist in early cancer detection.

What I have done so far:
Implemented U-Net architecture for image segmentation
Performed preprocessing on CT scan data (normalization, resizing)
Started training model for pancreas region detection

Current status:
Model is under development and optimization
Working on improving segmentation accuracy

Future work:
Integrating biomarker-based data with imaging
Enhancing model performance using advanced techniques

Tech stack:
Python
TensorFlow / PyTorch
NumPy, Matplotlib
